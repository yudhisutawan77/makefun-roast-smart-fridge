## The entry

> My smart fridge won't give me ice until it finishes updating, so my drink is held hostage by a Terms of Service I never read.

## How it works

`main.py` (Python 3.13, stdlib only) writes that single line — 125
characters, one line, nothing else — to the output path:

- `$ENTRY_OUT` (a file, or a directory, in which case `entry.txt` is
  written inside it)
- `$MAKEFUN_OUTPUT_DIR` (entry.txt inside that directory)
- otherwise `/output/entry.txt`, falling back to `./entry.txt`

Run it:

```sh
ENTRY_OUT=./out python3 main.py
```
